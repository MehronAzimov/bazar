# Проект «Базар-навигатор»

Приложение для поиска магазинов и товаров на базаре: схема рядов, маршрут, чат с продавцом.

## Документы
- docs/TZ.md — техническое задание (функции, база данных, API)
- docs/PZ.md — пояснительная записка (алгоритмы, архитектура, безопасность, тесты)
- docs/PLAN.md — план по шагам. Работаем строго по нему.

Перед задачей сверяйся с документами. Если код или моя просьба противоречит документам — спроси меня, не выбирай сам.

## Стек
- backend/: Java 21, Spring Boot 3, Gradle (Kotlin DSL), PostgreSQL 16 + pg_trgm, Flyway, JWT, MinIO, Bucket4j
- admin: Thymeleaf + HTMX внутри backend
- mobile/: Flutter 3, Riverpod, Dio, go_router, Drift
- Локальный запуск: docker-compose (postgres, minio)

## Правила работы
- Один шаг из PLAN.md за сессию. Не делай следующих шагов и не добавляй функции, о которых я не просил.
- Перед началом коротко опиши план шага и список файлов, дождись моего «да».
- Порядок: код → тесты → запуск тестов → отметка [x] в PLAN.md → короткий отчёт и команда для ручной проверки.
- Не меняй уже работающий код других модулей без необходимости; если нужно — сначала скажи зачем.

## Соглашения в коде
- Пакеты: tj.bazar.<модуль>.{controller, service, repository, dto, entity}
- Контроллеры не обращаются к репозиториям напрямую, только через сервисы.
- В API отдаём DTO, а не сущности.
- Схема БД меняется только новыми миграциями Flyway (V2__..., V3__...). Старые миграции не редактировать.
- Деньги — long в дирамах (1 сомони = 100 дирам). Даты — UTC, ISO 8601.
- Удаление магазинов, товаров, пользователей — мягкое (deleted_at).
- Ошибки API — формат RFC 7807.
- Проверка прав на каждом запросе: пользователь видит и меняет только своё.
- Секреты только в .env (есть .env.example). .env в .gitignore.
- Тесты: JUnit 5, Mockito, Testcontainers. Для Flutter — flutter_test.
- Комментарии, сообщения коммитов и отчёты — на русском.

## Команды
- Запуск зависимостей: docker compose up -d
- Бэкенд: cd backend && ./gradlew bootRun
- Тесты: cd backend && ./gradlew test
- Swagger: http://localhost:8080/swagger-ui.html
